## About 📖
`Tutorial` This is a modern, inventory-based Minecraft plugin designed to help server owners introduce, showcase, and teach different parts of their server to players through interactive GUI menus.

The plugin operates entirely through inventory-based interfaces, providing a clean and intuitive menu-driven experience. You can create engaging tutorial sections, guide players through server features, and enhance onboarding using interactive events and customizable GUI elements.

### Features 🔥
- **🧰 Inventory-Based System – Fully interactive GUI-driven design for a clean and intuitive user experience.**
- **🎯 Engaging Events – Includes a variety of interactive and exciting events to enhance player engagement**
- **🤝 User-Friendly – Designed with simplicity in mind, making it easy for both administrators and players to use.**
- **⚡ Easy Installation – Quick setup process with minimal configuration required.**
- **🎮 30 Built-in Events – Comes with over twenty ready-to-use events to create dynamic server experiences.**
- **🔌 No Dependencies Required – Works completely standalone with no external plugins needed.**
- **💎 100% Free – Completely free to use with no restrictions.**

### Recommended 💻
- **ProtocolLib: If installed, you can use it to enhance player visibility features.**
- **PlaceholderAPI: Enables the use of any placeholder you want. If not installed, you can still use the default placeholders.**

## 🚀 Getting Started

### Requirements
- **Java Version 17+** (We will add support for lower versions in future updates.)

### Installation

1. **Download the Latest Release**

   - Visit our [Releases](https://github.com/MenenTeX/Tutorial/releases) page
   - Download the latest version
  
2. **First Launch**

   - Place the plugin inside the plugins folder.
   - Turn on your server.
   - Now enjoy the plugin and train your players.
  
---

📚 **Commands**

| Commands                            | Description                                         |
| ----------------------------------- |-----------------------------------------------------|
| `/tutoedit create <tutorialName>`   | Create tutorial                                     |
| `/tutoedit delete <tutorialName>`   | Delete tutorial                                     |
| `/tutoedit save <tutorialName>`     | All actions and settings are saved in tutorials.yml |
| `/tutoedit reload <tutorialName>`   | Reload all .yml files                               |
| `/tutoedit open <tutorialName>`     | Open the tutorial menu                              |
| `/tutorial <tutorialName>`          | Starts the specified tutorial for the player        |
| `/tutorial <tutorialName> <target>` | Starts the specified tutorial for the player        |
| `/exit`                             | Exit from tutorial                                  |
| `/tutorial exit`                    | Exit from tutorial                                  |
